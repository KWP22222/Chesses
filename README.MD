# Chesses
Java-библиотека, реализующая правила шахмат: генерацию ходов, проверку шаха, рокировку, взятие на проходе и превращение пешки.

Технологии
    Java 21
    Maven
    JUnit 5

Модель
    Figure — sealed interface, 6 реализаций (Pawn, Knight, Bishop, Rook, Queen, King)
    Cell — record (клетка доски), автоматические equals/hashCode
    Position — неизменяемое состояние партии
    Board — доска 8x8, геттеры возвращают копии

Тесты
    12 тестовых сценариев покрывают:
    Генерацию ходов (20 ходов в начальной позиции)
    Рокировку, взятие на проходе, превращение пешки
    Проверку шаха
    Исключения при недопустимых ходах
    Контракт equals/hashCode
    Инкапсуляцию
